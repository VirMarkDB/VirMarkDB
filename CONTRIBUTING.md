# Contributing to VirMarkDB

Contributions to VirMarkDB are welcome.

## Types of contribution

Useful contributions include:

- adding missing viral taxa;
- adding reference proteins;
- adding reference genomes;
- correcting taxonomy;
- reporting suspicious marker assignments;
- improving marker group definitions;
- improving documentation;
- reporting reproducibility issues;
- suggesting new marker genes.

## Recommended workflow

1. Open an issue describing the proposed change.
2. Fork the repository.
3. Create a dedicated branch.
4. Modify the relevant files.
5. Check metadata consistency.
6. Open a pull request.

## Adding reference proteins

When adding reference proteins, please provide:

| Information | Description |
|---|---|
| Marker name | Marker gene associated with the protein |
| Protein accession | Stable protein identifier |
| Source | Publication, database, or manual curation source |
| Taxonomy | ICTV-compatible taxonomy when possible |
| Justification | Reason for adding the sequence |

## Adding reference genomes

When adding genomes, please provide:

| Information | Description |
|---|---|
| Genome accession | Stable genome accession |
| Virus name | Virus name from ICTV or source database |
| ICTV ID | ICTV identifier when available |
| Taxonomy | Kingdom to species when available |
| Source | ICTV, NCBI, publication, or manual curation |
| Comment | Optional note explaining the addition |

## Reporting issues

Potential issues include:

- suspicious marker assignment;
- missing taxon;
- unexpected absence of a marker;
- inconsistent taxonomy;
- duplicated genome entries;
- unclear workflow provenance.

Please include enough detail to reproduce or verify the problem.
