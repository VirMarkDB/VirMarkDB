# Changelog

All notable changes to VirMarkDB are documented here. 

## [0.1.0] - 2026-10-28
### Added
- Initial documented version of VirMarkDB, targeting ten marker genes across *Nucleocytoviricota*, *Pantevenvirales* and *Orthornavirae*.
- Version-controlled database-generation workflow, marker metadata, website documentation and descriptive coverage analyses.
